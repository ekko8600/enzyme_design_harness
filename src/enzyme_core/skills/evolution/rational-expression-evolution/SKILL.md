# Rational Expression And Evolution

- Use high-quality, sufficiently deep MSA evidence before consensus or ASR recommendations; frequency does not capture epistasis.
- Propose surface and interface changes with explicit solubility, oligomer-state, and activity trade-offs.
- Do not apply blanket Met/Cys replacement; require exposure, oxidation, and functional evidence.
- Use soluble expression, aggregation, SEC-MALS/AUC, storage, and retained-activity assays as appropriate.
