# 酸碱催化 + 水亲核底物 的 QM/MM 准备打法（葡糖淀粉酶 worked example）

针对**通过催化水/亲核水 + 广义酸碱残基**发生的反应（糖苷水解、酯酶、蛋白酶、磷酸酶等，
即绝大多数水解酶）。与 chorismate mutase（分子内周环、无水、无酸碱）互补——那类见
`chorismate_mutase_calibration.md`。本文由葡糖淀粉酶（glucoamylase GH15，翻转型糖苷水解）
的真实运行沉淀（2026-07；体系 80,939 原子，ΔE‡≈8 kcal/mol、放热、机理完整）。

## 何时用本打法
反应含以下任一：亲核**水**进攻、广义**酸**（Asp/Glu-COOH、His）质子化离去基、广义**碱**
（Asp/Glu-COO⁻、His）夺质子、共价中间体。识别催化残基：活性位点几何——酸的 -COOH 氧距
离去/scissile 杂原子 ~2.6-3.0 Å（H 键 donor）；碱距亲核原子/水 ~2.5-3.2 Å。

## 准备阶段的四个命门（都踩过坑，务必照做）

### 1. 手动放催化水（结构常无晶体水）
- 位置：**in-line** —— 沿"被进攻原子 → 离去基"的反向延长线，距被进攻碳 ~2.8 Å（背面进攻）。
- 校验：放好后该水 O 距广义碱的羧基氧应 ~2.6-3.2 Å（碱要能去质子化它）。
- 实现：按 `inline = C_attacked + (C_attacked - O_leaving)/|..| * 2.8`，H 之一朝向碱。

### 2. 质子化态（tleap 前改残基名）
- 广义**酸** → 质子化型（Glu→GLH / Asp→ASH / His→HID/HIE/HIP）；广义**碱**保持去质子。
- GLH/ASH 默认质子化的是某个 O——确认是**朝向受体**的那个氧（否则见坑 3）。

### 3. ★经典最小化必须"锁住反应几何"★（最易翻车）
全自由最小化会破坏精心摆好的催化几何。必须：
- **约束蛋白+底物重原子**（restraintmask `':1-<lastsolute> & !@H='`, wt~5）保住对接位姿；
- **距离约束钉住催化水**（NMR &rst：water-O ↔ 被进攻碳 ~2.8 Å，rk~30）——否则水会漂走
  （葡糖淀粉酶第一次没约束，水漂到 24+ Å 外）；
- **距离约束把广义酸的质子拉向离去基**（&rst：酸-H ↔ 离去杂原子 ~1.8 Å，rk~60）——
  tleap 加的羟基 H 会乱转到背离方向，导致酸催化失效（见坑 4）。
- 从"已约束好催化水的那次最小化"的 rst 出发再加酸质子约束，别从会漂的那次。

### 4. ★广义酸质子朝向 = 定量成败的关键★
**症状**：ΔE‡ 虚高（葡糖淀粉酶错向时得 35 vs 正确 8 kcal/mol）、产物**吸热**（+32 而非放热）、
剖面崎岖、产物不下降。
**根因**：广义酸的 O-H 指向背离离去基 → scissile 键断裂时离去基**未被质子化** → 生成高能
烷氧/负离子中间体。
**诊断**（务必做）：沿路径查两个质子距离——酸-H→离去杂原子、亲核水-H→碱氧。正确时应
从 ~1.5 逐步降到 ~1.0（转移完成）。用 `analyze_charges.py` 的电荷演化交叉验证：酸给质子应
变负、碱夺质子应变负→正、水亲核应变正、底物在 TS 处发展正电（氧碳正离子/类似）。
**修法**：坑 3 的酸质子距离约束；广义酸的 H 在 QM 区内，扫描时会自然完成转移，只需初始朝对。

## 反应坐标
反对称 RC = d(scissile 断键) − d(亲核原子–被进攻碳 成键)，COMBINE_COLVAR（`FUNCTION CV1-CV2`,
`ERROR_LIMIT 1.0E-6`）+ 刚性 restraint（见 ts_workflow / 通用扫描模板）。质子转移随重原子
RC 自然发生（酸/碱/水的 H 都在 QM 区）。先单窗验证两键协同响应再跑全程。

## QM 区（酸碱水解典型）
被进攻底物片段 + scissile 杂原子 + 邻接原子(在此切 link) + 催化水 + 广义酸侧链 + 广义碱侧链。
净电荷 = 各片段加和（去质子碱贡献 −1）。groups.json 映射见 SKILL.md（CP2K 按 QM_KIND C→H→O
重编号，link 帽子排最后）。

## 突变候选（本打法产出）
`analyze_ts_electrostatics.py`：TS 静电逐残基分解（残基 MM 场 × QM 电荷变化 Δq(TS−R)）。
ΔE<0 稳定 TS（催化核心，保守）；ΔE>0 去稳定（中和它→候选提 kcat）。金标准验证=对 Top 候选
建突变体重跑反应路径比 ΔE‡。葡糖淀粉酶实例：保守 Glu181/Glu406/Asp55/Trp52/Trp122；
活性候选 Asp178→Asn、Glu108→Gln。
